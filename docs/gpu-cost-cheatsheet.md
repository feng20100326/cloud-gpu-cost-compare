## 1. 按场景选（先做这一步，别看价格先看需求）

| 你的任务 | 推荐 | 为什么 |
|---|---|---|
| 学习 / 写 demo / 验证想法 | Colab 免费版 → Kaggle 免费额度 | 0 成本；官方明确"不保证、不限量、限制浮动"，只能当"能开始" |
| 数据清洗 / 批量推理 / 可断点续跑 | SaladCloud "Lowest" 档 | $0.015/hr 起、按秒计费；**官方原话：这一档最便宜也最容易被中断**（可能被高优先级抢占，重分配前最短约30分钟） |
| 训练 / 微调，要连续跑完 | RunPod 按秒计费托管机 | 4090 24G $0.89/hr、L4 24G $0.69/hr、A6000 48G $0.69/hr、RTX 6000 Ada 48G $1.09/hr、H100 PCIe 80G $2.89/hr（Secure）；按秒计费，断了损失极小 |
| 要大显存（48G / 80G） | 直接比这一档 | 差价主要在这里；别在 24G 档纠结 |
| 想多供应商比价、随时开关 | 按小时撮合的市场型平台（如 Clore.ai） | 价格随实时供给浮动；**机器来自第三方算力所有者，可靠性参差，必须自己压测验证，不是云厂商 SLA**；磁盘一般另计 |

## 3. 成本压到最低的 7 步检查清单

1. **先确认能不能不用 GPU**：能用 CPU 跑完的，别开卡。
2. **先测显存峰值再定机型**：用免费额度跑 10 分钟，记录峰值显存，而不是凭感觉买大卡。
3. **默认按秒计费**：需要计费的平台一律选按秒/按秒计价的机型，跑完立刻关机，别买月包。
4. **分开算存储**：镜像、checkpoint、数据集常常是另一笔账，只看 GPU 单价会低估总成本。
5. **优先"能断点续跑"的档位**：SaladCloud 官方写明 Lowest 档"最便宜也最容易被中断"；跑整段长任务就别用这档。
6. **区分"免费"和"免费且稳定"**：Colab/Kaggle 免费额度解决"能不能开始"，付费按时租解决"能不能按时跑完"。
7. **算总账时把抢占成本算进去**：中断一次重跑，损失的不只是那几毛钱机器时间，还有你的调试时间。

---

## 4. 一句话选型

> 只写代码 → 免费额度；批量可断点 → 最低价档（接受中断）；要跑完 → 按秒托管机；要大显存 → 直接比 48G/80G 档；想比价 → 市场型平台（自己压测）。
